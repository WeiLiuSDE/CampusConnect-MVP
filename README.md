# 🎓 CampusConnect MVP

## 📖 Overview
CampusConnect is a student portal designed to eliminate administrative friction by unifying campus services, event discovery, and academic advising into a single, mobile-responsive dashboard. 

This Minimum Viable Product (MVP) was developed under an accelerated agile schedule as a functional, clickable prototype.
